# Decisions

## 2026-07-18 — Tài liệu dự án bằng Obsidian

- Mở thư mục gốc của dự án làm Obsidian Vault.
- Lưu các ghi chú có giá trị với dự án trong `docs/notes/` để Codex và Git cùng sử dụng.
- Không theo dõi thư mục `.obsidian/`, vì nó chứa thiết lập giao diện và plugin riêng của máy.

## 2026-07-18 — Dữ liệu học cá nhân không vào Git

- `user_data/` được bỏ qua trong Git vì chứa tiến độ học và điểm số local.
- Dữ liệu mẫu dùng cho ứng dụng vẫn nằm trong `src/main/resources/data/`.
